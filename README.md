# Моментум на криптовалютном рынке

Курсовая работа с алгоритмом построения моментум-портфеля и историческим тестом на данных Binance. Стратегия ранжирует криптоактивы по накопленной доходности, формирует длинные и короткие позиции и сравнивает базовый моментум с вариантами на основе ставки финансирования, разброса доходностей между активами и волатильности.

- [Основной бэктест на R](R/conditional-momentum-backtest.R) сравнивает окна формирования и удержания портфелей.
- [Поправка на финансирование и комиссии](R/funding-and-fees.R), [статистические тесты](R/statistical-tests.R) и [графики](R/performance-plots.R) помогают сравнить варианты стратегии.
- [Бенчмарки](R/benchmarks/) содержат классическую, контртрендовую, long-only и минимизирующую дисперсию версии.
- [Прототип на Python](python/momentum_backtest.py) взят из отдельного эксперимента с торговым алгоритмом. Он строит веса и считает доходность по переданному ряду исторических доходностей.

[Ноутбук загрузки данных Binance](notebooks/binance-market-data.ipynb) показывает, как собраны свечи спота и фьючерсов и история ставок финансирования. Скрипты R читают CSV из `data/` с именами, указанными в начале файлов. Для графиков и статистики также нужны промежуточные файлы `.Rdata` исходного эксперимента. Это архив исследовательских скриптов для поэтапного запуска в RStudio или Jupyter. Исторические выгрузки и результаты расчётов нужно подготовить отдельно.
